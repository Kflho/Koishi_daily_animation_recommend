# 开发辅助工具

两份本机小工具，用来给插件准备数据。它们不进仓库：工具是一次性的，转换出来的数据才要提交。

## Excel 转 JavaScript 数组

文件：`程序.html`、`xlsx.core.min.js`、`说明书.txt`

把 Excel 表格转成可以直接粘进源码的 JS 数组字面量。

用法：

1. 浏览器打开 `程序.html`；
2. 选择 Excel 文件，页面读出工作表内容；
3. 按 `F12` 打开控制台，复制打印出来的数组；
4. 粘到插件 `src/` 里对应数据表的位置。

转换结果是一整行字面量。要改数据就回 Excel 改完重新转一次，不要直接在源码里手工改结构。

## Excel 转 enazo 题库

文件：`convert.html`、`megumin.txt`、`output (1).txt`（示例输入与输出）

把「中文名 / 日文名 / 备注」这类表格转成 enazo 题库的行格式：

```text
中文名,日文名$备注
```

没有备注的行只输出 `中文名,日文名`。

用法：

1. 浏览器打开 `convert.html`；
2. 选择 Excel 文件，页面直接给出转换结果；
3. 点「下载 output.txt」保存，或从页面复制。

## 工具和仓库的关系

- 两份工具已收进 [`javascript_projects`](https://github.com/Kflho/javascript_projects) 仓库的 `utils/`，那份是版本管理来源；本机另外的工作副本不算；
- 一个项目一个仓库，开发和日常使用共用这一份；开发专用内容（临时数据、本机配置）靠 `.gitignore` 排除，不另开镜像仓库；
- 工具本身不随本仓库发布；它们生成的数据（数组、题库文本）才是提交进本仓库的产物。
